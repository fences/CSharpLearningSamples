# 🏭 Industrial Conveyor Belt & Filling Monitor
### شبیه‌ساز نوار نقاله و مانیتورینگ خط پرکن مایعات

این پروژه یک نرم‌افزار **HMI (Human-Machine Interface)** شبیه‌سازی شده با C# WinForms است که عملکرد یک خط تولید بطری مایعات را مدیریت می‌کند. هدف اصلی این پروژه، آموزش کار با **آرایه‌ها (Arrays)**، **تایمرها**، **حلقه‌ها** و پیاده‌سازی منطق‌های کنترلی صنعتی مانند **Shift Register** و **Safety Interlocks** است.

---

## 📋 ویژگی‌های کلیدی پروژه

### ۱. شبیه‌سازی نوار نقاله (Shift Register Logic)
- استفاده از یک **آرایه ۱۰ تایی** (`int[] belt`) به عنوان مدل نوار نقاله.
- در هر تیک تایمر، داده‌ها یک واحد به جلو شیفت پیدا می‌کنند (حرکت بطری روی نوار).
- شبیه‌سازی پر شدن تصادفی بطری‌ها (بین ۲۳۵ تا ۲۶۰ میلی‌لیتر).

### ۲. کنترل کیفیت هوشمند (Dynamic Quality Control)
- **Set Point قابل تنظیم:** کاربر می‌تواند حداقل مقدار مجاز مایع (مثلاً ۲۴۵ ml) را تعیین کند.
- **تشخیص خطا:** سیستم به صورت خودکار بطری‌هایی که کمتر از حد مجاز پر شده‌اند را شناسایی کرده و با علامت `!` نشان می‌دهد.
- **آلارم وضعیت:** اگر تعداد خطاها در لحظه بیش از ۳ مورد باشد، وضعیت سیستم به **قرمز (بحرانی)** تغییر می‌کند.

### ۳. پنل اپراتور و ایمنی (Safety & Interlocks)
- **دکمه Start/Stop:** کنترل روشن و خاموش شدن خط تولید.
- **قفل ایمنی (Safety Interlock):** هنگام روشن بودن دستگاه، تغییر `Set Point` یا زدن دکمه `Clear` غیرفعال می‌شود تا از خطای انسانی جلوگیری شود.
- **جلوگیری از باگ:** منطق برنامه طوری نوشته شده که از خطای "تقسیم بر صفر" (Division by Zero) هنگام محاسبه میانگین جلوگیری می‌کند.

### ۴. سیستم ریست و پاکسازی (System Clear) 🆕
- امکان پاکسازی کامل خط تولید (صفر کردن آرایه).
- پاک کردن لاگ‌های سیستم و ریست کردن نمایشگرها.
- **شرط ایمنی:** این دکمه فقط زمانی فعال است که خط متوقف باشد.

## 🛠 تحلیل فنی کد (برای دانشجویان)

### الف) منطق حرکت نوار (Shift Register)
مهم‌ترین بخش این پروژه، حرکت دادن داده‌ها در آرایه است. این کار دقیقاً مشابه رجیسترهای شیفت در PLC عمل می‌کند:
```csharp
// حلقه معکوس: از آخرین خانه شروع می‌کنیم و مقدار قبلی را در آن می‌ریزیم
for (int i = belt.Length - 1; i > 0; i--)
{
belt[i] = belt[i - 1];
}
// خانه اول (belt[0]) حالا خالی است و آماده دریافت بطری جدید می‌باشد

```

### ب) محاسبه میانگین با محافظت (Average Calculation)
برای جلوگیری از کرش کردن برنامه وقتی نوار خالی است (بعد از دکمه Clear)، از شرط زیر استفاده شده است:

```csharp
double average = 0;
// productCount تعداد بطری‌های غیر صفر است
if (productCount > 0) 
{
average = (double)sum / productCount;
}
// اگر شرط برقرار نباشد، میانگین همان 0 باقی می‌ماند و برنامه خطا نمی‌دهد

```
### ج) دکمه پاکسازی (The Clear Logic)
در دکمه `btnClear`، ما با یک حلقه ساده تمام حافظه سیستم (آرایه) را بازنویسی می‌کنیم:

```csharp
for (int i = 0; i < belt.Length; i++)
{
belt[i] = 0; // "خالی کردن" فیزیکی بطری از روی نوار
}
lstLog.Items.Clear(); // پاک کردن تاریخچه
```

## 🚀 راهنمای کاربری (User Manual)

1.  **تنظیمات اولیه:** قبل از روشن کردن خط، مقدار **Min Level SetPoint** را روی عدد دلخواه (مثلاً ۲۴۵) تنظیم کنید.
2.  **شروع به کار:** دکمه `START Line` را بزنید. نوار نقاله شروع به حرکت می‌کند و بطری‌ها وارد می‌شوند.
3.  **مانیتورینگ:**
*   بطری‌های سالم به صورت `[250]` نمایش داده می‌شوند.
*   بطری‌های معیوب (کمتر از SetPoint) به صورت `[240!]` نمایش داده می‌شوند.
*   آمار میانگین و تعداد خطاها در پایین صفحه به‌روز می‌شود.
4.  **توقف و ریست:**
*   برای تغییر تنظیمات یا پاکسازی، ابتدا دکمه `STOP Line` را بزنید.
*   پس از توقف، دکمه `Clear System` فعال می‌شود که تمام داده‌ها را پاک می‌کند.
