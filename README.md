# 🏭 Project 3: Industrial Temperature Control Simulation (Hysteresis & On-Delay)

پروژه شماره ۳: شبیه‌سازی سیستم کنترل دما با منطق هیسترزیس و تایمر تاخیر

## 📋 درباره پروژه
این پروژه یک سیستم کنترل دمای صنعتی را شبیه‌سازی می‌کند. هدف اصلی، یادگیری نحوه مدیریت **وضعیت‌ها (States)**، استفاده از **چندین تایمر** برای اهداف مختلف، و پیاده‌سازی مفاهیم مهم صنعتی مانند **Hysteresis** (برای جلوگیری از نوسان) و **On-Delay Logic** (برای حذف نویز) است.

در این سیستم، دما به صورت خودکار بالا می‌رود و در صورت عبور از حد مجاز (SetPoint)، پس از یک مکث ایمنی (Delay)، فن خنک‌کننده روشن می‌شود.

## 🎯 اهداف آموزشی (Learning Objectives)
در این تمرین شما با مفاهیم زیر آشنا می‌شوید:
1.  **Logic & State Management:** استفاده از متغیرهای `bool` برای نگهداری وضعیت سیستم (روشن/خاموش بودن فن).
2.  **Dual Timers Strategy:** استفاده از دو تایمر مجزا؛ یکی برای شبیه‌سازی محیط (Physics) و دیگری برای منطق زمان‌سنجی (Logic).
3.  **Debouncing / On-Delay:** جلوگیری از فعال‌سازی آنی آلارم با استفاده از تایمر تاخیر (مشابه رله‌های زمانی صنعتی).
4.  **Hysteresis (هیسترزیس):** جلوگیری از قطع و وصل مکرر (Chattering) فن در مرز دمای تنظیمی.

## 💡 تحلیل منطق (Code Logic Breakdown)

### ۱. استراتژی دو تایمر (Dual Timer)
چرا از دو تایمر استفاده کردیم؟
*   **`tmrSimulation` (100ms):** این تایمر محیط فیزیکی را شبیه‌سازی می‌کند. دما باید نرم و روان بالا یا پایین برود. اگر این تایمر کند باشد، گرافیک لگ خواهد داشت.
*   **`tmrDelay` (1000ms):** ما نیاز داریم زمان خطا را به "ثانیه" بشماریم. استفاده از تایمر جداگانه محاسبات را ساده می‌کند و منطق ایمنی را از منطق گرافیکی جدا می‌سازد.

### ۲. مفهوم هیسترزیس (Hysteresis)
در صنعت، اگر دما روی ۸۰ درجه تنظیم شده باشد، نباید فن دقیقاً روی ۷۹ خاموش شود. چرا؟ چون دما فوراً دوباره به ۸۰ می‌رسد و فن مدام روشن/خاموش می‌شود (Chattering) که باعث سوختن موتور می‌شود.
**راه حل:** فن در ۸۰ روشن می‌شود، اما تا دما به ۶۵ (۱۵ درجه پایین‌تر) نرسد، خاموش نمی‌شود.
```csharp
// شرط خاموش شدن فن (Hysteresis Logic)
if (isFanOn == true && currentTemp < (setPoint - 15))
{
isFanOn = false; // فن خاموش شود
}

### ۳. منطق تاخیر در وصل (On-Delay)
هر افزایش دمایی خطرناک نیست (شاید نویز سنسور باشد). ما فقط زمانی فن را روشن می‌کنیم که دما **۳ ثانیه مداوم** بالا باشد.
*   اگر دما بالا رفت -> تایمر `tmrDelay` استارت می‌خورد.
*   اگر قبل از ۳ ثانیه دما پایین آمد -> تایمر ریست می‌شود (Debouncing).
*   اگر ۳ ثانیه گذشت -> فن روشن می‌شود.

## 🚀 نحوه اجرا (Getting Started)
1.  پروژه را کلون کنید یا فایل Zip را دانلود نمایید.

5.  دکمه **START** را بزنید و بالا رفتن دما را تماشا کنید.
