# CSharp Learning Samples

این مخزن شامل مجموعه‌ای از پروژه‌های آموزشی زبان C# است که به صورت تدریجی و تمرین‌محور توسعه داده می‌شوند.

هدف این ریپازیتوری ارائه مثال‌های ساده، قابل اجرا و کاربردی برای درک بهتر مفاهیم C# و .NET است. هر پروژه روی یک یا چند مفهوم مشخص تمرکز دارد و به گونه‌ای طراحی شده که بتوان آن را به راحتی اجرا، بررسی و توسعه داد.

این مخزن به مرور زمان تکمیل‌تر می‌شود و پروژه‌های جدید به آن اضافه خواهند شد.

اگر در حال یادگیری C# هستید، می‌توانید از این پروژه‌ها برای تمرین، مرور مفاهیم و توسعه مهارت‌های برنامه‌نویسی خود استفاده کنید.
