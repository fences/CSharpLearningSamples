# C# Learning Samples - Day 5

این پوشه شامل نمونه‌های آموزشی روز پنجم دوره‌ی یادگیری C# است.  
تمرکز این روز بر **ماشین حالت (State Machine)**، **کنترل خط تولید ساده** و **مدیریت داده‌ها با آرایه‌ها** است.  

پروژه‌های این روز:

- **Sample1**: شبیه‌سازی چرخه پر کردن بطری با نوار نقاله و حالت اضطراری  
- **Sample2**: ذخیره و تحلیل داده‌های دما با آرایه و محاسبات آماری  
- **Sample3**: شبیه‌سازی نوار نقاله با بررسی خطا و نمایش گرافیکی وضعیت بطری‌ها  

---

## پیش‌نیازها

- Visual Studio 2019 یا بالاتر  
- .NET Framework 4.7.2 یا بالاتر  
- آشنایی با Windows Forms، Timer و آرایه‌ها در C#  

---

## پروژه‌ها

### Sample1 - Bottling Line Simulation with State Machine

**توضیح پروژه:**

این پروژه یک **خط پر کردن بطری** را شبیه‌سازی می‌کند که شامل سه مرحله اصلی است:

1. **MOVING IN**: ورود بطری به زیر نازل  
2. **FILLING**: پر کردن بطری  
3. **MOVING OUT**: خروج بطری و آماده‌سازی برای بطری بعدی  

همچنین امکان **حالت اضطراری (Emergency Stop)** و **ریست سیستم** وجود دارد.  

**ویژگی‌ها:**

- استفاده از **State Machine** برای مدیریت مراحل  
- تایمر اصلی (`tmrMain`) برای شبیه‌سازی حرکت و پر کردن بطری  
- کنترل وضعیت اضطراری و تغییر رنگ UI برای هشدار  
- ProgressBar برای نوار نقاله و بطری  
- نمایش وضعیت جاری در Label  

**اجرای پروژه:**

1. پروژه `CSharpLearingDay5-S1` را باز کنید.  
2. فرم `Sample1` را اجرا کنید.  
3. دکمه **Start** را فشار دهید تا چرخه پر کردن بطری آغاز شود.  
4. برای تست ایمنی، دکمه **Emergency Stop** را فشار دهید و سپس با **Reset** سیستم را بازگردانید.

### Sample2 - Temperature Data Collection and Analysis

**توضیح پروژه:**

این پروژه ذخیره داده‌های دما را در **آرایه‌ای با طول ثابت 10 خانه** شبیه‌سازی می‌کند و محاسبات آماری انجام می‌دهد:

- وارد کردن 10 عدد دما توسط کاربر  
- محاسبه **میانگین، بیشینه و کمینه**  
- نمایش گزارش و وضعیت حافظه  

**ویژگی‌ها:**

- استفاده از آرایه ثابت به‌عنوان **Buffer مشابه PLC**  
- کنترل ورود داده‌ها و جلوگیری از پر شدن بیش از حد  
- ProgressBar برای نمایش وضعیت حافظه  
- Button برای محاسبات آماری  
- Label و ListBox برای نمایش گزارش  

**اجرای پروژه:**

1. پروژه `CSharpLearingDay5-S2` را باز کنید.  
2. فرم `Sample2` را اجرا کنید.  
3. دماها را وارد کرده و دکمه **Add** را فشار دهید.  
4. پس از وارد کردن 10 نمونه، دکمه **Calculate** فعال می‌شود و نتایج آماری نمایش داده می‌شوند.  
5. برای شروع مجدد، دکمه **Reset** را فشار دهید.

### Sample3 - Conveyor Line Simulation with Error Detection

**توضیح پروژه:**

این پروژه یک **خط نقاله با 10 خانه** را شبیه‌سازی می‌کند که بطری‌ها با مقادیر پر شدن تصادفی وارد خط می‌شوند:

- بررسی مقدار پر شدن هر بطری نسبت به SetPoint  
- نمایش وضعیت هر بطری و شمارش خطاها  
- تغییر رنگ وضعیت در صورت بحرانی شدن (Error Count ≥ 3)  
- امکان پاکسازی سیستم (Clear)  

**ویژگی‌ها:**

- استفاده از **آرایه برای شبیه‌سازی نوار نقاله**  
- شبیه‌سازی بطری‌های جدید با مقادیر تصادفی  
- محاسبه میانگین و شمارش خطاها  
- نمایش گرافیکی وضعیت نوار و بطری‌ها  
- مدیریت Start/Stop و Reset سیستم  

**اجرای پروژه:**

1. پروژه `CSharpLearingDay5-S3` را باز کنید.  
2. فرم `Sample3` را اجرا کنید.  
3. SetPoint حداقل مقدار بطری را تنظیم کنید.  
4. دکمه **START Line** را فشار دهید تا شبیه‌سازی آغاز شود.  
5. خطاهای بحرانی با رنگ قرمز نمایش داده می‌شوند و لاگ‌ها ثبت می‌شوند.  
6. برای پاکسازی داده‌ها، دکمه **Clear** را فشار دهید.
