# 🏭 Temperature Data Logger (Industrial Array Analysis)

## 📌 Project Overview | معرفی پروژه
این پروژه یک شبیه‌ساز **دیتالاگر صنعتی** است. در بسیاری از سیستم‌های PLC و مانیتورینگ، داده‌های سنسورها در یک "بافر" (Buffer) ذخیره شده و سپس پردازش می‌شوند. هدف این برنامه، دریافت ۱۰ نمونه دمایی و استخراج اطلاعات آماری حیاتی از آن‌هاست.

## 🎯 Educational Goals | اهداف آموزشی
- درک مفهوم **Fixed-size Arrays** (آرایه‌های با طول ثابت).
- استفاده از متغیر **Global** برای نگهداری ایندکس آرایه.
- استفاده از حلقه **`for`** برای پیمایش (Iteration) و جمع‌زنی داده‌ها.
- پیدا کردن الگوریتم‌های **Min/Max** با استفاده از حلقه و شرط.
- جلوگیری از خطای معروف **Index Out of Range**.

## 🛠 Features | قابلیت‌ها
- **Data Entry Limits:** محدودیت ورود دقیقاً ۱۰ داده (شبیه‌سازی بافر سخت‌افزاری).
- **Statistical Analysis:** محاسبه خودکار:
  - میانگین دما (Average)
  - داغ‌ترین نقطه (Max Temp)
  - سردترین نقطه (Min Temp)
- **Visual Feedback:** نمایش وضعیت پر شدن حافظه با ProgressBar.

## 💻 Code Logic Snippet | منطق کلیدی
```csharp
// Finding Max value inside a loop
int maxVal = temps[0];
for (int i = 1; i < temps.Length; i++)
{
if (temps[i] > maxVal)
{
maxVal = temps[i];
}
}

```

## 🚀 How to Run | راهنمای اجرا
1. برنامه را اجرا کنید.
2. در کادر متنی، یک عدد (مثلاً دمای کوره) وارد کنید و دکمه **Add** را بزنید.
3. این کار را ۱۰ بار تکرار کنید تا حافظه پر شود.
4. دکمه **Calculate Analysis** فعال می‌شود (یا خودتان روی آن کلیک کنید).
5. نتایج آماری در پایین فرم نمایش داده می‌شود.
