# 🚰 Project 1: Water Tank Level Control System

پروژه شماره ۱: سیستم کنترل سطح مخزن (پرکن و تخلیه خودکار)

## 📋 درباره پروژه
این پروژه یک سیستم اتوماسیون ساده برای مدیریت سطح مایع در یک مخزن صنعتی را شبیه‌سازی می‌کند. هدف اصلی، یادگیری نحوه استفاده از **Timer** برای ایجاد فرآیندهای مداوم و استفاده از **Logic (منطق شرطی)** برای تصمیم‌گیری بین حالت پر کردن (Filling) و تخلیه (Draining) است.

در این سیستم، یک پمپ آب مخزن را پر می‌کند، مگر اینکه "شیر تخلیه" باز باشد که در آن صورت مخزن خالی می‌شود. همچنین سیستم دارای محافظت‌های نرم‌افزاری برای جلوگیری از سرریز شدن (Overflow) یا خشک کار کردن پمپ است.

---

## 🎯 اهداف آموزشی (Learning Objectives)
در این تمرین شما با مفاهیم زیر آشنا می‌شوید:
1.  **Timer Loop:** استفاده از تایمر به جای حلقه‌های `while` برای انجام کارهای تکراری بدون فریز کردن برنامه.
2.  **Basic Protection Logic:** نوشتن شرط (`if`) برای جلوگیری از منفی شدن یا بیش از حد شدن مقادیر (Bounds Checking).
3.  **UI Updates:** تغییر متن و رنگ لیبل‌ها (`Label`) بر اساس وضعیت لحظه‌ای سیستم.
4.  **Boolean Flags:** استفاده از متغیر `bool` برای مدیریت وضعیت دکمه استارت/استپ.

فرم خود را طبق جدول زیر طراحی کنید. نام‌گذاری دقیق کنترل‌ها (Name) بسیار مهم است:

| Control Type | Name (ID) | Property Settings | توضیحات |
| :--- | :--- | :--- | :--- |
| **Button** | `btnStartStop` | Text: "Start" | دکمه اصلی برای روشن/خاموش کردن پمپ |

## 💡 تحلیل منطق (Code Logic Breakdown)

### ۱. منطق پر کردن و تخلیه (Fill vs Drain)
برنامه در هر تیک تایمر (هر ۱۰۰ میلی‌ثانیه)، وضعیت `chkDrainValve` را چک می‌کند:
*   **اگر تیک خورده باشد (Drain Mode):** یعنی شیر باز است -> سطح آب کم می‌شود (`Value -= 1`).
*   **اگر تیک نخورده باشد (Fill Mode):** یعنی شیر بسته است -> سطح آب زیاد می‌شود (`Value += 1`).

### ۲. حفاظت در برابر خطا (Safety Logic)
در صنعت و برنامه‌نویسی، مقادیر نباید از حد مجاز خارج شوند.
*   **محافظت پایین (Low Limit):** هنگام خالی شدن، چک می‌کنیم `if (prgLevel.Value > 0)`. اگر به صفر رسیدیم، پمپ خاموش می‌شود تا خشک کار نکند.
*   **محافظت بالا (High Limit):** هنگام پر شدن، چک می‌کنیم `if (prgLevel.Value < 100)`. اگر به ۱۰۰ رسیدیم، سیستم **آلارم** می‌دهد و متوقف می‌شود.
```csharp
// مثال: جلوگیری از سرریز شدن
if (prgLevel.Value < 100)
{
prgLevel.Value += 1; // هنوز جا دارد
}
else
{
// مخزن پر شده! توقف اضطراری
lblStatus.Text = "ALARM: TANK FULL!";
lblStatus.ForeColor = Color.Red;
tmrProcess.Stop(); 
}
```
### ۳. دکمه Toggle (Start/Stop)
ما از یک متغیر کمکی به نام `_startStatus` استفاده می‌کنیم تا بفهمیم سیستم الان روشن است یا خاموش.
*   اگر `false` بود -> روشن کن، متن دکمه را "Stop" کن.
*   اگر `true` بود -> خاموش کن، متن دکمه را "Start" کن.

## 🚀 نحوه اجرا (Getting Started)
1.  کد را دانلود و پروژه را در Visual Studio باز کنید.
2.  برنامه را اجرا کنید (F5).
3.  دکمه **Start** را بزنید (مخزن شروع به پر شدن می‌کند).
4.  وسط کار، تیک **Open Drain Valve** را بزنید (مخزن شروع به خالی شدن می‌کند).
5.  اجازه دهید مخزن کامل پر شود تا عملکرد **ALARM** را ببینید.

## 🔧 چالش‌های تمرینی (Challenges)
برای تسلط بیشتر، سعی کنید این قابلیت‌ها را اضافه کنید:

1.  **Water Color:** وقتی مخزن در حال پر شدن است رنگ نوار (`ProgressBar`) سبز باشد، و وقتی در حال خالی شدن است زرد شود (نکته: رنگ ProgressBar استاندارد ویندوز به سختی عوض می‌شود، شاید لازم باشد رنگ `lblStatus` را عوض کنید).
2.  **Reset Button:** یک دکمه اضافه کنید که مقدار مخزن را صفر کند و آلارم‌ها را پاک کند (فقط زمانی کار کند که سیستم Stop است).
3.  **Sensor Indicators:** دو تا `PictureBox` دایره‌ای شکل بگذارید. یکی وقتی مخزن خالی است قرمز شود (Low Sensor) و یکی وقتی مخزن پر است قرمز شود (High Sensor).
