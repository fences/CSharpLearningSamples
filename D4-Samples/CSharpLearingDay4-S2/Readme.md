# 📦 Project 2: Smart Conveyor Belt Simulation (Quality Control)

پروژه شماره ۲: شبیه‌سازی نوار نقاله هوشمند با سنسور کنترل کیفیت

## 📋 درباره پروژه
این پروژه یک خط تولید صنعتی (Conveyor Belt) را شبیه‌سازی می‌کند. هدف اصلی، یادگیری نحوه ایجاد **انیمیشن‌های ساده صنعتی** با استفاده از `ProgressBar`، مدیریت **سرعت فرآیند** با تغییر `Timer Interval` و پیاده‌سازی منطق **شمارنده شرطی** است.

در این سیستم، محصولات روی نوار نقاله حرکت می‌کنند و فقط در صورتی شمارش می‌شوند که سنسور کیفیت (Quality Sensor) آن‌ها را تأیید کند.

---

## 🎯 اهداف آموزشی (Learning Objectives)
در این تمرین شما با مفاهیم زیر آشنا می‌شوید:
1.  **Motion Simulation:** استفاده از `ProgressBar` برای شبیه‌سازی حرکت فیزیکی اشیاء.
2.  **Process Configuration:** تغییر سرعت خط تولید با استفاده از `ComboBox` و تأثیر آن بر `Timer.Interval`.
3.  **Sensor Logic:** شبیه‌سازی یک سنسور دیجیتال (0/1) با استفاده از `CheckBox`.
4.  **Conditional Counting:** شمارش محصولات بر اساس شرط (Accept/Reject).

## 💡 تحلیل منطق (Code Logic Breakdown)

### ۱. کنترل سرعت (Speed Control)
در صنعت، سرعت موتورها با درایو (Inverter) کنترل می‌شود. در نرم‌افزار، ما سرعت را با تغییر زمان تیک‌زدن تایمر (`Interval`) تغییر می‌دهیم.
*   **Fast:** فاصله زمانی ۵۰ میلی‌ثانیه (حرکت سریع).
*   **Slow:** فاصله زمانی ۳۰۰ میلی‌ثانیه (حرکت کند).
```csharp
// تنظیم سرعت بر اساس انتخاب کاربر
if (cmbSpeed.Text == "Fast")
{
tmrMain.Interval = 50; // سریع‌تر تیک می‌زند
}
else
{
tmrMain.Interval = 300; // کندتر تیک می‌زند
}
```
### ۲. شبیه‌سازی حرکت (Motion Logic)
ما از `ProgressBar` به عنوان نوار نقاله استفاده می‌کنیم. در هر بار تیک زدن تایمر، مقدار آن را افزایش می‌دهیم (`Value += 2`).
زمانی که مقدار به ۱۰۰ رسید، یعنی محصول به انتهای خط رسیده است. در این لحظه:
1.  نوار را صفر می‌کنیم (محصول بعدی وارد می‌شود).
2.  بررسی می‌کنیم که آیا محصول سالم است یا خیر.

### ۳. منطق سنسور و شمارش (Sensor & Counting)
در انتهای خط، ما وضعیت `chkQualitySensor` را چک می‌کنیم.
*   اگر تیک خورده باشد (`true`): یعنی سنسور کیفیت محصول را تأیید کرده -> **شمارش کن**.
*   اگر تیک نخورده باشد (`false`): یعنی محصول معیوب است -> **شمارش نکن**.

```csharp
if (chkQualitySensor.Checked == true)
{
_productCount++; // افزایش شمارنده
lblStatus.Text = "Accepted Item!";
}
else
{
lblStatus.Text = "Rejected Item!"; // محصول دور انداخته شد
}
```

## 🚀 نحوه اجرا (Getting Started)
1.  کد را دانلود و در ویژوال استودیو باز کنید.
2.  پروژه را بیلد کنید (`Ctrl + Shift + B`).
3.  برنامه را اجرا کنید.
4.  از لیست کشویی سرعت **"Fast"** را انتخاب کنید.
5.  دکمه **Start** را بزنید.
6.  تیک **Quality Sensor** را بردارید و بگذارید تا ببینید محصولات شمارش نمی‌شوند (Rejected).

## 🔧 چالش‌های تمرینی (Challenges)
برای اینکه مهارت خود را محک بزنید، این تغییرات را اعمال کنید:

1.  **Rejected Counter:** یک لیبل جدید اضافه کنید که تعداد محصولات خراب (Rejected) را هم بشمارد.
2.  **Emergency Stop:** اگر کاربر سرعت را حین حرکت تغییر داد، برنامه باید چه واکنشی نشان دهد؟ (اکنون باید Stop کنید و دوباره Start کنید. سعی کنید کاری کنید که بدون توقف سرعت عوض شود).
3.  **Visual Feedback:** کاری کنید وقتی محصول `Accepted` می‌شود، نوشته سبز شود و وقتی `Rejected` می‌شود، قرمز شود (`lblStatus.ForeColor`).

### نکات آموزشی برای تدریس روی این کد:

1.  **Scope متغیرها:** حتماً توضیح دهید چرا `_productCount` را بیرون از متدها (در سطح کلاس) تعریف کردیم. (چون اگر داخل `btn_Click` یا `tmr_Tick` بود، با هر بار اجرا مقدارش صفر می‌شد و نمی‌توانستیم شمارش را نگه داریم).
2.  **تبدیل نوع:** اشاره کنید که `lblCount.Text = _productCount.ToString();` چقدر مهم است. اعداد (`int`) نمی‌توانند مستقیم در متن (`string`) ریخته شوند.
3.  **منطق حلقه (Loop) بدون `for`:** تایمر در واقع یک حلقه بی‌نهایت (`while(true)`) است که با سرعت کنترل‌شده اجرا می‌شود. این مفهوم در PLCها هم دقیقاً به همین شکل است (Cycle Time).
