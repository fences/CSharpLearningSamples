# C# Learning Samples - Day 4

این مخزن شامل نمونه‌های آموزشی روز چهارم دوره‌ی یادگیری C# است.  
هدف این روز تمرین با **Windows Forms**، **Timers** و **کنترل ساده پروسه‌ها** است.  

پروژه‌های این پوشه به سه بخش تقسیم شده‌اند:

- **Sample1**: شبیه‌سازی پر و خالی شدن یک مخزن با کنترل دستی شیر تخلیه
- **Sample2**: شبیه‌سازی نوار نقاله با کنترل سرعت و شمارش محصولات
- **Sample3**: شبیه‌سازی سیستم گرمایش با کنترل دما و فن خنک‌کننده

---

## پیش‌نیازها

- Visual Studio 2019 یا بالاتر
- .NET Framework 4.7.2 یا بالاتر
- آشنایی پایه با Windows Forms و Timer

---

## پروژه‌ها

### Sample1 - Tank Filling/Draining Simulation

**توضیح پروژه:**

این پروژه یک مخزن را شبیه‌سازی می‌کند که می‌تواند **پر شود یا تخلیه شود**.  
- اگر شیر تخلیه فعال باشد، سطح مخزن کاهش می‌یابد (Drain Mode)  
- اگر شیر تخلیه غیر فعال باشد، سطح مخزن افزایش می‌یابد (Filling Mode)  

**ویژگی‌ها:**

- استفاده از **ProgressBar** برای نمایش سطح مخزن  
- تایمر (`Timer`) برای شبیه‌سازی پر و خالی شدن مخزن  
- دکمه Start/Stop برای کنترل فرآیند  
- نمایش پیام وضعیت: Filling، Draining، Tank Full یا Empty Tank  

**اجرای پروژه:**

1. پروژه `CSharpLearingDay4-S1` را باز کنید.  
2. روی فرم `Sample1` اجرا کنید.  
3. با فعال یا غیرفعال کردن **Drain Valve** و فشار دکمه **Start** فرآیند را مشاهده کنید.

---

### Sample2 - Conveyor Belt Simulation

**توضیح پروژه:**

این پروژه یک **خط نقاله** را شبیه‌سازی می‌کند و شامل شمارش محصولات است.  
- نوار نقاله با سرعت انتخابی حرکت می‌کند (Fast یا Slow)  
- وقتی محصول به انتهای خط رسید، سنسور کیفیت بررسی می‌شود  
  - اگر سالم باشد، محصول شمارش می‌شود  
  - اگر خراب باشد، رد می‌شود  

**ویژگی‌ها:**

- کنترل سرعت نوار نقاله با **ComboBox**  
- شمارش محصولات پذیرفته شده  
- نمایش وضعیت محصول: Accepted / Rejected  
- استفاده از **ProgressBar** برای نمایش حرکت نوار نقاله  
- تایمر (`Timer`) برای شبیه‌سازی حرکت نوار  

**اجرای پروژه:**

1. پروژه `CSharpLearingDay4-S2` را باز کنید.  
2. فرم `Sample2` را اجرا کنید.  
3. سرعت نوار نقاله را انتخاب کرده و دکمه **Start** را فشار دهید.  
4. مشاهده حرکت نوار و شمارش محصولات با فعال یا غیرفعال کردن **Quality Sensor**.

### Sample3 - Heating System Simulation

**توضیح پروژه:**

این پروژه یک سیستم گرمایش را شبیه‌سازی می‌کند که دارای **کنترل دما و فن خنک‌کننده** است.  
- دما با تایمر شبیه‌سازی می‌شود  
- اگر دما از SetPoint بیشتر شود، تایمر تأخیر شروع می‌شود  
- پس از 3 ثانیه دمای بالا، فن خنک‌کننده روشن می‌شود  
- سیستم شامل **حالت روشن/خاموش و Hysteresis برای فن** است  

**ویژگی‌ها:**

- کنترل دما با **TextBox** برای SetPoint  
- نمایش وضعیت دما و فن با **ProgressBar و Label**  
- تایمر برای شبیه‌سازی پروسه گرمایش/سرمایش  
- تایمر On-Delay برای تأخیر فعال‌سازی فن  
- جلوگیری از نوسانات سریع (Chattering) با Hysteresis  

**اجرای پروژه:**

1. پروژه `CSharpLearingDay4-S3` را باز کنید.  
2. فرم `Sample3` را اجرا کنید.  
3. SetPoint دلخواه را وارد کنید و سیستم را با **Start** روشن کنید.  
4. مشاهده روند گرمایش و عملکرد فن در نمودار و Label ها.

- مدیریت Start/Stop و وضعیت‌های مختلف پروسه
